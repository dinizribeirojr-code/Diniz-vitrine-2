> Observação: como as fotos são carregadas do Unsplash, é preciso conexão com a
> internet para exibi-las. Para uma versão 100% offline (ou com as fotos reais
> da AMV), basta baixar as imagens para uma pasta `fotos/` e trocar os endereços
> `https://images.unsplash.com/...` pelos arquivos locais.
